# 💫 About Me:
I am a Backend Developer & Tech Lead with strong experience in building scalable and production-ready backend systems. Over the years, I have developed solid programming skills in Python, Java, and SQL, along with hands-on experience in frameworks like Django, FastAPI, and Flask.<br><br>

I have worked as a Backend Developer, contributing to API development, system design, third-party integrations, and production deployments. I have also been involved in code reviews, debugging, and collaborating with teams to deliver reliable and efficient solutions.<br><br>

I am skilled in database management systems such as PostgreSQL, MongoDB, MySQL, SQLite, and Firebase. My technical expertise includes designing RESTful APIs, working with WebSockets, Django Channels, event-driven architectures using RabbitMQ, and handling real-world challenges like rate limiting, retries, and notifications.<br><br>

I have experience deploying and managing applications on AWS EC2 and working with tools like Docker, Postman, and Linux-based systems.<br><br>

Beyond my technical abilities, I enjoy playing badminton, competitive esports, listening to music, traveling, and watching movies. I am always eager to build impactful systems and grow as a backend engineer.
